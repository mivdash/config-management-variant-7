# Конфигурационное управление · Вариант 7

CLI читает конфигурационный файл в UTF-8, разбирает его с помощью Lark,
вычисляет константные выражения и выводит TOML в стандартный вывод.

## Установка и запуск

Требуется Python 3.11 или новее. Компиляция не требуется.

Windows (PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\run.bat --input examples/server.cfg
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Linux/macOS:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
./run.sh --input examples/server.cfg
.venv/bin/python -m unittest discover -s tests -v
```

| Ключ | Назначение |
| --- | --- |
| `-i PATH`, `--input PATH` | Обязательный путь к входному файлу UTF-8 |
| `-h`, `--help` | Справка CLI |

При успехе код завершения равен 0. Ошибки чтения или трансляции
выводятся в stderr с кодом 1. Ошибки аргументов CLI дают код 2.

## Синтаксис

| Конструкция | Пример |
| --- | --- |
| Однострочный комментарий | `* Текст до конца строки` |
| Целое число | `0`, `+17`, `-3` |
| Строка | `@"Привет"` |
| Вложенный массив | `list(1, @"текст", list(-3, 0))` |
| Пустой массив | `list()` |
| Объявление константы | `base := 16` |
| Сложение | `.{+ base 5}.` |
| Вычитание | `.{- base 5}.` |
| Квадратный корень | `.{sqrt(base)}.` или `.{sqrt base}.` |
| Вложенное выражение | `.{+ .{sqrt(base)}. 3}.` |

Имена состоят из строчных латинских букв. В числах разрешён знак,
ведущие нули запрещены. В строках поддерживаются экранирования JSON,
например `\n` и `\"`. Комментарии и пробельные символы между токенами
игнорируются.

Константы вычисляются сверху вниз и записываются как ключи TOML.
Объявление доступно в следующих вычислениях. Повторное объявление и
ссылка на неизвестную константу вызывают ошибку. Операции принимают
числа, квадратный корень от отрицательного числа вызывает ошибку.
Дробный результат записывается числом TOML. Отдельные значения верхнего
уровня записываются в массив TOML `_values` в порядке появления.

## Устройство программы

- `src/config.lark` задаёт грамматику входного формата для Lark.
- `convert(source)` разбирает исходный текст и возвращает TOML.
- `Evaluator` обходит дерево разбора, разрешает ссылки на константы и
  вычисляет операции. `encode_toml(value)` сериализует полученные значения.
- `main()` обрабатывает аргументы, читает файл и печатает результат либо
  диагностическое сообщение.
- Тесты проверяют конструкции языка, вложенность, ошибки и запуск CLI.

## Примеры

| Область | Входной файл | Фрагмент результата |
| --- | --- | --- |
| Веб-сервер | [server.cfg](examples/server.cfg) | `connections = 150` |
| Складской учёт | [warehouse.cfg](examples/warehouse.cfg) | `available = 85` |
| Геометрия | [geometry.cfg](examples/geometry.cfg) | `side = 7.0710678118654755` |

Чтобы перенаправить результат в файл, можно использовать, например,
`./run.sh --input examples/warehouse.cfg > warehouse.toml`.

## Этапы работы

1. Добавить чтение файла и разбор литералов.
2. Добавить массивы list.
3. Добавить объявления констант.
4. Вычислять префиксные выражения.
5. Добавить три конфигурации и документацию.
